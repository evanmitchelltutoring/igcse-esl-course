The rule · copy this into your notes

Started in the past, still going

Form: have / has + been + verb-ing.   I have been studying. She has been practising.
When to use it
An action that began in the past and continues now, or that explains a recent result.
My focus has improved because I've been studying every day.
for vs since
for + a length of time: for two years.
since + a start point: since September.
Watch it: don't drop been ("I have studying" → "I have been studying") · state verbs (know, believe) don't take it — use present perfect simple.
show me
See the lift · weak vs strong

Same idea — flat, then alive

Weak
"I study at the library. My focus is good now. I do it a long time."
Present simple; no sense of duration or effort.
Strong
"I've been studying at the library since September, and my focus has really improved because I've been going every day."
Ongoing effort + since + a clear result.

Find and fix

1. I have been studying French for two years. (add been)
2. She has been practising for three months. (a length → for)
3. We have been learning to code all term. (been + -ing)
4. He has been studying every evening. (been + -ing)
5. They have been improving since September. (a start point → since)
6. I've known her for years. (know is a state verb → perfect simple)

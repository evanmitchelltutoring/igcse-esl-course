The rule · copy this into your notes

Two tools: the unreal if, and adding detail

Second conditional
If + past simple, would + base form.
If esports were in the Olympics, more schools would fund it.
Relative clauses
who people · which/that things · where places.
A champion is a player who never gives up.
Watch it: no would in the if-clause ("If I would train…" → "If I trained…") · use were for all persons in the unreal if ("if I were captain").

Practice 1 · spot the error

Find and fix one mistake in each

1. If I would train harder, I would win.
2. If he practised more, he will score more goals.
3. If we had more players, we can win.
4. I would be happy if I win a medal.
5. If they were fitter, they would played better.
6. What would you do if you was the captain?
Support → check each half: if + past simple, and would + base form.
Stretch → which sentence needs were, not was? Why?

Find and fix

1. If I trained harder, I would win. (no would in the if-clause)
2. If he practised more, he would score more goals. (would in the result)
3. If we had more players, we would / could win.
4. I would be happy if I won a medal. (unreal → past simple)
5. If they were fitter, they would play better. (would + base form)
6. What would you do if you were the captain? (unreal were)

Practice 2 · transform

Make a second conditional (Q6 adds a relative clause)

1. (I / be / taller → I / play / basketball)
2. (we / have / a coach → we / train / better)
3. (she / not be / injured → she / run / the marathon)
4. (they / practise / more → they / win / more matches)
5. (you / be / the referee → what / you / do?)
6. Join with a relative clause: "A champion is a person. This person never gives up."
Support → start with If + subject + past-simple verb, then the would half.
Stretch → add a relative clause to one of your conditional sentences.
Answer · mark your own

Make the conditional

1. If I were taller, I would play basketball.
2. If we had a coach, we would train better.
3. If she were not injured, she would run the marathon.
4. If they practised more, they would win more matches.
5. If you were the referee, what would you do?
6. A champion is a person who never gives up.
